# Bank Customer Churn Analysis | Power BI, SQL & Excel

## Project Overview

The Bank Customer Churn Analysis project focuses on analyzing customer data to understand customer churn, retention, account activity, and product usage. The project uses data analysis and visualization techniques to present insights through an interactive Power BI dashboard.

## Project Objectives

- Analyze customer churn and retention patterns.
- Understand customer activity and product usage.
- Explore customer characteristics associated with churn.
- Build an interactive dashboard to summarize customer data.
- Present insights that can help support customer retention decisions.

## Tools & Technologies

- **Power BI** – Dashboard development and data visualization
- **SQL** – Data querying and analysis
- **Microsoft Excel** – Data preparation and analysis
- **DAX** – Calculated measures and analytical metrics
- **Power Query** – Data cleaning and transformation

## Dataset

The project uses bank customer data, including information such as customer demographics, geography, account activity, credit card status, product usage, and churn status.

## Key Analysis Areas

- Customer Overview
- Churn Analysis
- Product and Credit Analysis
- Active and inactive customer analysis
- Customer distribution by demographic categories

## Key Metrics

- Total Customers
- Churned Customers
- Churn Rate
- Retention Rate
- Active Customers
- Active Member Percentage
- Product Distribution

## Dashboard Pages

### 1. Customer Overview
Provides a summary of the customer base and important customer metrics.

### 2. Churn Analysis
Explores customer churn and retention patterns.

### 3. Product & Credit Analysis
Examines product usage, credit card status, and customer activity.
